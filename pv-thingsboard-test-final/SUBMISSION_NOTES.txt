Пакет для тестового задания:

1. docker-compose.yml — ThingsBoard CE + PostgreSQL, persistent volume, environment variables, restart policy.
2. emulator/pv_emulator.py — реалистичный эмулятор ПВУ с MQTT telemetry.
3. emulator/requirements.txt — Python dependencies.
4. .env.example — пример конфигурации без секретов.
5. README.md — инструкция по запуску, telemetry и логике модели.

Перед отправкой приложить отдельно:
- скриншот Dashboard с идущими данными;
- при желании второй скриншот PV-01 -> Latest telemetry;
- короткое описание выполненной работы (текст из сообщения работодателю).

Не отправлять .env: в нём находится реальный Access Token устройства.
